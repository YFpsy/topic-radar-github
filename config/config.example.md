# 私有运行配置清单（示例，不是 Hermes 可直接执行的配置文件）

此文件仅列出部署时要核对的项目。请在自己设备上建立**不纳入 Git** 的私有配置；不要在本文件填写真实密钥、个人路径或笔记内容。不同 Hermes 版本的配置格式和 Profile 目录可能不同，先检查本机帮助信息及实际读取行为。

| 配置项 | 你需要私下确认的内容 | 公共仓库中的值 |
| --- | --- | --- |
| `profile_id` | 一个独立、未与其他 Agent 共用的 Hermes Profile 名称 | `<your-profile-id>` |
| 运行 Profile 文件 | 当前 Hermes 实际读取的文件及其创建方式 | `<verify-with-your-hermes-version>` |
| 账号定位 | 授权可读的定位文件 | `<private-path>` |
| 关键词与历史内容 | 授权可读的素材、选题、草稿和复盘 | `<private-paths>` |
| 结果目录 | 仅允许写入的素材卡、选题池和日报位置 | `<private-output-path>` |
| 模型 | 使用者自己的模型配置与用量限制 | `<configure-privately>` |
| 公开搜索 | 使用者自己的搜索工具及只外发非敏感查询的规则 | `<configure-privately>` |
| 飞书 | 使用者自己的机器人、授权用户/群、消息事件与 Gateway | `<configure-privately>` |
| 定时任务 | 可选；先通过手动端到端测试，再决定是否启用 | `未配置` |

## 部署前检查

- [ ] 已验证 Hermes 识别**唯一**的新 Profile，启动时实际读取的是哪个文件。
- [ ] 模板中的路径和权限已经改成自己的真实配置，且私有文件没有进入 Git 暂存区。
- [ ] 搜索服务只收到必要的非敏感关键词和公开 URL，不收到原始笔记、草稿、个人信息或密钥。
- [ ] 飞书触发身份与群聊 `@` 条件经过实测，陌生用户不能运行任务。
- [ ] 模型与搜索服务的密钥保存在各自官方支持的私有配置位置，未写入公开文档。
- [ ] 已设置可接受的运行成本和并发限制；失败时不会连续自动重试。
- [ ] 完整测试后核对飞书回执、素材卡、选题池和日报，写入仅追加且能够重新读取。

本公开包没有真实 API KEY、App Secret、机器人权限、Obsidian 笔记或 Hermes 运行 Profile。若未来添加新的部署文档，先做一次密钥与隐私扫描，再提交到公开仓库。
