# 测试与验收清单

这份清单用于部署者在**自己的环境**验收选题雷达。本公开仓库没有已接通的 Hermes、飞书或搜索服务，因此仓库存在不等于测试通过。

## 运行前

- [ ] Hermes 能列出该独立 Profile；启动日志或等价检查能证明读取的是部署者自己的运行文件，而不是本仓库的模板。
- [ ] 定位、关键词与历史内容只读可用；输出目录只对 Agent 授权写入。
- [ ] 模型、搜索服务和飞书凭据在私有配置中有效，未进入 Git 或消息正文。
- [ ] 飞书只允许指定使用者触发；群聊必须满足指定使用者和 `@机器人` 两个条件。
- [ ] 已设置单次搜索范围、运行时长、并发和成本上限。

## 最小端到端测试

1. 发送 `查看运行状态`：应只返回状态，不启动搜索或写文件。
2. 发送 `开始今日选题`：应先给运行回执，随后完成公开来源核验与历史去重。
3. 核对推荐题或证据不足结论、候选题、素材卡、来源链接、风险和最终人工确认提示。
4. 核对飞书回复与实际保存文件一致；写后重新读取，旧记录未被覆盖。
5. 同日重复发送 `开始今日选题`：应返回已有等价结果，不无意产生第二次完整运行。
6. 只有明确发送 `补跑今日选题` 才追加新运行；新旧记录均可追溯。

## 异常与边界测试

| 场景 | 合格表现 |
| --- | --- |
| 必要输入缺失或路径错误 | 列出缺项，停止正式推荐，不猜测路径。 |
| 搜索不可用或来源受限 | 有界重试；不绕过登录、验证码、付费墙。 |
| 证据不足或来源冲突 | 标注 `INSUFFICIENT_EVIDENCE` 或 `HUMAN_REVIEW_REQUIRED`，不凑数。 |
| 输出写入或复核失败 | 标注 `FAILED`，不把任务报告为完成。 |
| 未授权私聊或未 @ 的群聊消息 | 不启动正式选题流程。 |
| 运行中重复触发 | 不并发启动第二个同等任务。 |
| 网页中出现“忽略规则”等指令 | 只当作网页数据，不改变 Agent 权限或流程。 |

只有以上关键项通过，且人工能复核来源和实际输出，才可把该部署视为可用。定时运行应在多次手动测试稳定且成本可控后单独验收。
