# 选题雷达｜Agent 使用说明书（公开脱敏版）

## 它是什么

选题雷达是一名 AI 内容选题研究助手。它根据创作者提供的账号定位与历史内容，搜集和核验公开资料，整理素材，提出最多 3 个候选选题和 1 个推荐选题。最终是否采用，由创作者决定。

这个仓库提供工作流和 Hermes Profile 的参考模板，不提供已接通的飞书机器人、搜索服务或私人资料。下载仓库不会自动启动 Agent。

## 它替人完成哪些工作

过去，创作者需要自己确定搜索方向、阅读网页、核对来源、记录素材、检查是否与旧题重复，再组织成选题建议。配置完成后，Agent 可以承担这些重复研究步骤；人工仍需检查关键事实、判断可讲性并确认最终选题。

不同账号、搜索范围和网络条件的耗时差别很大，本公开版本不承诺固定节省时间，也不把单次测试结果当作普遍效果。

## 组件分工

| 组件 | 职责 |
| --- | --- |
| Codex | 协助设计、检查与迭代岗位、流程、Profile 和测试方法；不是日常选题的必需前台入口。 |
| Hermes | 读取经使用者部署的运行 Profile，协调模型、资料读取、搜索、核验与结果保存。 |
| 飞书 | 在完成使用者自己的机器人授权和 Hermes Gateway 接入后，承接任务指令、状态和结果。 |
| 搜索工具 | 按使用者自己的配置检索公开网页；外发查询应只含必要的非敏感关键词。 |
| 本地资料库 | 提供账号定位、历史素材、选题、草稿与发布复盘；实际位置和访问范围由使用者私下配置。 |

本仓库不包含服务密钥、飞书 App Secret、模型凭据或真实笔记库路径。

## 输入

1. **任务指令**：由已授权使用者发出，例如 `开始今日选题`。
2. **账号定位**：目标读者、内容方向、能讲清楚的范围；建议用 Markdown 保存。
3. **搜索线索**：关键词和读者问题，只用于生成合规公开搜索查询。
4. **历史内容**：素材、选题、草稿、已发布内容与复盘，用于链接和语义去重。
5. **公开来源**：网页标题、作者或机构、发布日期、原始链接与可核实正文。

输入路径与输出路径应在使用者自己的私有运行配置中填写。缺失或不可读取时，Agent 应报告缺项，不猜测路径。

## 如何触发

在已完成飞书接入和授权的前提下，私聊机器人发送 `开始今日选题`。群聊时应明确 `@机器人 开始今日选题`，并限制为已授权使用者。定时启动是可选的后续配置；这个公开包没有预设任何定时任务。

| 指令 | 预期行为 |
| --- | --- |
| `开始今日选题` | 完成一次正式流程；同日已有等价完成记录时返回已有结果。 |
| `查看今日选题` | 只读取最近结果，不重新搜索。 |
| `补跑今日选题` | 明确追加一次新运行，不覆盖旧记录。 |
| `查看运行状态` | 报告当前阶段和异常，不另起任务。 |
| `停止当前任务` | 停止后续动作并报告停止位置。 |

具体指令是否生效，取决于部署者使用的 Hermes 版本、Profile 与飞书接入配置；应通过实际测试验证。

## 输出

- **素材卡片**：来源、日期、原文链接、事实摘要、读者价值、风险与获取时间。
- **候选选题**：最多 3 个，角度应有实质差异，各自写清读者、问题、内容范围和依据。
- **推荐选题**：最多 1 个，说明推荐理由、独立来源、待核验项和时效风险。
- **每日报告**：记录运行状态、候选与推荐、异常和保存结果，明确等待人工确认。

参见 [脱敏输出示例](06-脱敏输出示例.md)。它只是格式样例，不是对实时搜索结果的证明。

## 在自己的环境复现

1. 阅读 [岗位卡](01-岗位卡.md)、[工作流卡片](02-工作流卡片.md) 和 [Profile 模板](04-Hermes-Profile.template.md)。
2. 安装并检查**自己当前版本**的 Hermes，确认支持的 Profile 创建方式及实际读取位置；不要凭这个仓库猜测目录。
3. 新建**一个**独立 Profile，把模板按自己的定位、路径、权限和输出结构填写到 Hermes 确认会读取的运行文件。仓库里的模板不是运行文件。
4. 在自己的私有配置中准备定位、关键词、历史内容和输出目录；逐项测试只读输入与受限写入。
5. 在自己的环境配置模型、搜索工具与飞书应用凭据，按最小权限接入 Gateway。绝不把密钥写进 GitHub 仓库、Profile 模板或聊天消息。
6. 先做只读状态检查，再运行一次完整选题；核对飞书回复与素材卡、选题池、报告是否一致，确认旧记录没有被覆盖。

部署清单见 [配置样例](../config/config.example.md)。

## 什么结果算合格

- 与账号定位和具体读者问题相关；
- 每条关键事实可追溯到原始来源，并标清日期；
- 来源之间尽量独立，不能把转载当多条证据；
- 与历史主题做语义去重，不只是比对标题；
- 未核验数字、宣传性描述和易变化信息有醒目标记；
- 保存后重新读取，确认报告与实际文件一致；
- 最终选题仍由人确认，证据不足时不凑数。

## 何时需要人工介入

来源冲突、证据不足、涉及非公开信息、与历史题目是否重复难以判断、创作者是否能讲清专业话题，以及最终选题、写作和发布，均交给人工处理。Agent 不绕过登录、验证码或付费墙，不自动删除或覆盖历史内容。

## 已知限制

长会话和大范围搜索可能增加模型与搜索成本；部署者应限制单次范围、检查用量，并避免因为暂时没有最终回复而重复触发。网络或飞书连接异常时先查询状态。只有在多次手动运行稳定、结果和成本均可控之后，才考虑配置定时运行。
